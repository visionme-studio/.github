## What we do

An emotional savings app guided by an avatar representing the user's Future Self.

1. **Future Self avatar** — an emotional anchor that makes saving feel personal
2. **Automated micro-savings** — Soroban contracts execute deposits securely and transparently
3. **USDC on Stellar** — savings that hold stable value while settling instantly
